# Contributing

Thank you for wanting to help. Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md). How to contribute is in the [Building and contributing](README.md#building-and-contributing) section of the README, and what to install to build and check your changes is in [docs/building.md](docs/building.md).

In short: open issues and pull requests on GitHub, keep commits small with a message like `gfx: batch circles with instancing`, write rocinante in lowercase, and run `odin run build -- ci --fast` before you push.
