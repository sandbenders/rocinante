a small language for drawing and animating

rocinante is for people who want to make pictures, animations and interactive pieces with code, without first learning a programming language's machinery. One line makes a picture:

circle at 100 100 radius 50

Save the file and the window changes while it runs. Mistakes never stop it: the window keeps the last good picture and says, in plain words, what went wrong and what would work.

guides

Learn it a topic at a time: shapes, movement, input, lists, collision, windows, the turtle, verbs of your own.

reference

Every word of the language, each with an example and the picture it draws.

messages

Everything rocinante can tell you when something is wrong, with a sketch that makes each message.

start

  1. roci new my-sketch

    makes a sketch folder with one circle in it

  2. cd my-sketch
  3. roci run

    opens the window; change sketch.roci and save

This is an alpha: the language and these pages will still change. The getting started guide says how to install it.
