This is a record with pos and radius. A line to cast is a record made with `from` and `to`. A shape is a vector, which is a point, or a record with `pos` and `radius` for a circle, `pos` and `size` for a rectangle, with `angle` to turn it, `from` and `to` for a line, or `points` for any outline.

For example:  h = cast { from: { 0, 0 }, to: mouse } walls
