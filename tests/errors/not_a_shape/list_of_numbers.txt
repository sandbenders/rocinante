This is a list of numbers. Each of its items has to be a shape. A shape is a vector, which is a point, or a record with `pos` and `radius` for a circle, `pos` and `size` for a rectangle, with `angle` to turn it, `from` and `to` for a line, or `points` for any outline. With three numbers in its places a shape is in space: a vector of 3 is a point, `pos` and `radius` make a sphere, `pos` and `size` a box that is not turned, and `from` and `to` a line.

For example:  walls = [ { from: { 0, 0 }, to: { 400, 0 } } ]
