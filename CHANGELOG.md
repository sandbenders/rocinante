# Changelog

rocinante keeps no history in this file. The notes for each release are written on its tag and published on the [releases page](https://github.com/sandbenders/rocinante/releases).

There are no releases yet. Versions follow `YYYY.MINOR.MICRO` (see [Versions](README.md#versions)), and releases before the first stable one are marked as previews. From the first stable release on, any change that breaks existing sketches is listed at the top of its release notes, with the fix for each.
